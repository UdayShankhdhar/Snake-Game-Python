## Features

A classic Snake Game developed using Python and Pygame with an interactive graphical interface.

## Features
- 🎮 Interactive Main Menu
- 🐍 Smooth Snake Movement
- 🍎 Random Food Generation
- 🔊 Sound Effects
- 🌴 Custom Jungle Background
- ⏸ Pause and Resume
- 🔁 Restart After Game Over
- 🌐 Wall Wrap-around
- ⌨ Keyboard Controls

## Technologies Used
- Python
- Pygame

## Installation

```bash
pip install pygame
```

## Run

```bash
python snakeGame.py
```

## Controls

- Arrow Keys → Move
- P → Pause/Resume
- R → Restart
- Q → Quit
